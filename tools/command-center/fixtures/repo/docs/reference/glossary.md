# Glossary

The words of the sample product Burrow, in alphabetical order. This is a made-up doc for the tests of the command center.

## Index

The notes that Burrow keeps about your files. See [the setup guide](../guides/setup.md#storage) for where it lives.

## Journal

A short line for every run, written when the run ends.

## Quokka

The mascot of the sample product: a small, cheerful marsupial. It appears in the logo and nowhere else.
