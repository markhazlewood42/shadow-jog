## What it covers

Hao Wang's 1961 edge-matching tiles, Berger's aperiodic result and use in games.

## Key points, in my words

- Square tiles with a colour on each side must match neighbours with no rotation or reflection.
- In games a set of 16 tiles can handle transitions between two terrains.

## Best for

The origin of the name and the one-line rule.

## Caveats

Game artists use the name loosely for corner-matched sets.
