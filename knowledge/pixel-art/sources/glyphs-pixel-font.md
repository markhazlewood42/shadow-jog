# Glyphs: Creating a Pixel Font

Part of the [[projects/shadow-jog/knowledge/pixel-art/README|pixel-art library]]. Link: https://glyphsapp.com/learn/pixelfont

- **Author:** Glyphs (font editor documentation)
- **Kind:** Reference (tool tutorial)
- **How I read it (2026-10-01):** Read in full.

## What it covers

Setting up a grid, vertical metrics, spacing and export for a pixel font in Glyphs.

## Key points, in my words

- Snap everything to a grid; each component is one grid square.
- Set cap height, x-height, ascender and descender metrics as guides.
- Tighten default spacing by setting the sidebearing to a single pixel width.

## Best for

Metrics and spacing basics for a bitmap font.

## Caveats

About the Glyphs tool; there is little on legibility design.
