## What it covers

The difference between UX and UI and how to show health and other resources.

## Key points, in my words

- UX is how the interface behaves, UI is what it looks like; both aim for consistency and at-a-glance readability.
- Hearts are charming but imprecise, numbers are exact but hard to read in action; bars should share one orientation and language.
- Animate UI only to serve function; feedback is often better near the character.

## Best for

Principles for resource displays.
