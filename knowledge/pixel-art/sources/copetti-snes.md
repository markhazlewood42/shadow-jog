# Rodrigo Copetti: Super Nintendo Architecture

Part of the [[projects/shadow-jog/knowledge/pixel-art/README|pixel-art library]]. Link: https://www.copetti.org/writings/consoles/super-nintendo/

- **Author:** Rodrigo Copetti
- **Kind:** Reference (hardware)
- **How I read it (2026-10-01):** Read the graphics sections in full.

## What it covers

The S-PPU: resolution, colour depth, sprites, background modes.

## Key points, in my words

- 256 by 224 (NTSC); up to 256 colours at once; sprites built from up to 16 tiles, 128 per frame and 32 per scanline.
- Eight background modes (Mode 7 does affine transformation); colour math allows transparency effects.

## Best for

Numbers for comparison with the Mega Drive.
