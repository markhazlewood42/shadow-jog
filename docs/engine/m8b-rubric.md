Score each of 10 items /10. Gate (Mark, 2026-10-14): average >= 8.5, no item below 7, no Critical/Important finding.
Scope: port the 13 UI scenes to native `sje` scenes (card, controls, gameover, ending, placemap, saveload; options, dialog, title, shop; deck, panels, menu) and build editor items (d) and (e) for dialog and shop. Sources: `m8-brief.md` sections 4, 5, 6, 7; `m8a-data-format.md`; `migration.md` (M8b row).
1. Layout and unit tests: pass line 7 holds. `tests/layout.test.ts`, `tests/ui-layout.test.ts` and every unit test that touches a UI scene are green and run against the ported scenes. No test is deleted or loosened. `npm run check` exits 0.
2. Specs: pass lines 6 and 9 hold for the 13 scenes. Title, menu, shop, save and load, options each run once with the real scene. The playthrough and gameover specs are green (`CI=1 PW_PORT=3012`).
3. No legacy: pass line 4 holds for UI scenes. `git grep -n "from '../engine/game'" src/scenes` prints nothing for the 13 files. Each class extends the sje `Scene` (or `UiScene`). No ported scene imports a file M8d deletes (`engine/game`, `display`, `postfx`, `moments`). Control: the same scan on `main` prints files.
4. Kit reuse: scenes use `src/sje/ui/` (`TextObject`, `NineSlice`, `ListMenu`, bar, cursor). No scene copies kit logic. The kit gains no game state and no import of `engine/game`. Plain `Graphics` is allowed only for the divider, the select highlight and `OVERLAY_DIM`.

6. Editor contract (a) and (b): scenes read text and numbers from `src/data/*`, the `ui/draw.ts` palette and the font. No visible value changes. Dialog and shop still load from the approved data files and match `m8a-data-format.md`. The loader, checker, round trip and hot-reload tests stay green.
7. Editor contract (d) and (e), dialog: `snapshot()` and `restore()` capture the line and the choice position, and a restore resumes the same view. A deterministic `step(n)` scrubs the text reveal: the same n gives the same output, and step(0) differs from step(end). Each has a test with a control that goes red when the code is broken.
8. Editor contract (d) and (e), shop: `snapshot()` and `restore()` capture stock and cursor. Round trip equals the original. `step(n)` is deterministic for shop animation. Same test and control rule as item 7. The kit still takes plain data (contract c).

A flag with a clear reason does not lower the score. A silent change does. Pass line 8: `tests/sje-ui-leak.test.ts` still shows no leak with the ported scenes.

A reader (haiku) describes each picture and flags a blank or broken one. There is no pixel comparison test.
