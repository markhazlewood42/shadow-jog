# M8c verifier rubric (written before verification, 2026-10-15)

Score each of 10 items /10. Gate (Mark, 2026-10-14): average >= 8.5, no item below 7, no Critical/Important finding.
Scope: port `src/scenes/battle.ts` with `src/scenes/battlekit/` (group E, task 8) and `src/scenes/field.ts` with `src/scenes/fieldkit/` (group F, task 9) to native `sje` scenes over `BattleStageScene` and `FieldStageScene`. Calls to `postfx` and `moments` go to `game.fx`. Sources: `m8-brief.md` sections 4, 5, 6, 7; `migration.md` (M8c row).
1. Checks: pass line 1 holds. `npm run check` exits 0 (judge by exit code). Every unit test that touches battle, field, their kits or their seams is green and runs against the ported scenes. No test is deleted or loosened.
2. Battle control: the seed 7 status trace equals `battleTrace(7)` (the M3 control). A test proves it with the ported scene, and the test goes red when the trace changes. `e2e/sje-battle.spec.ts`, `e2e/battletest.spec.ts` and `e2e/sje-stage-parity.spec.ts` are green.
3. Field control: `e2e/playthrough.spec.ts`, `e2e/sje-field.spec.ts` and `e2e/sje-field-parity-a` to `-d` are green. The world map, town, outpost and dungeon floors load and walk as before.
4. Specs: pass lines 6 and 9 hold. The full pass line 6 list exits 0 with `CI=1 PW_PORT=3012` (`prod.spec` with the preview on 3008, stopped by PID). Gameover, economy, gpufx, shots (revert `docs/screenshots` after), playtest, chaos, default-path and canaries are green.
5. No legacy: pass line 4 holds for all scenes. `git grep -n "from '../engine/game'" src/scenes` prints nothing. Every scene class extends the sje `Scene`. `Game.run(oldScene)` has no caller in `src/`. Battle and field do not import `engine/postfx` or `engine/moments`. Control: the same scan on `main` prints `battle.ts` and `field.ts`.
6. Seams: `stageseam.ts` and `liveopen.ts` lose the old `Game` type. `fieldseam.ts`, `fieldopen.ts` and `fieldstage/stagescene.ts` lose `postfx`. The seams keep `snapshot`, `restore`, `loadStage` and `loadMap` unchanged (editor contract d). Battle Test (`src/dev/stageedit/`) still opens and runs a battle.
7. Effects and timing: each old `postfx` and `moments` call has a `game.fx` (or sje) equal with the same timing, strength and order: shake, flash, hitstop, fades, banners, transitions. A test or a trace shows the timing for at least hitstop, shake and the battle-in transition. No effect is silently dropped. If an effect has no sje equal, it is flagged, not faked.
8. Fit with the engine design: the scenes use the sje `Scene` lifecycle, `sys` and the stage scenes as `docs/engine/scene-graph.md` and `interfaces.md` say. No new shim or adapter that M8d must delete, unless the Record names it. No non-null assertions in `src/engine/` or `src/battle/`. The kits hold no new global state.
9. Hard lines kept: pass line 10 (`git diff --stat main...HEAD -- src/data src/battle src/field src/art src/audio src/story` prints nothing). Line 13 (`npm run budget` exits 0 against first play 412 kB and total 473.8 kB, and the total does not rise without a flag). Line 12: `git diff --stat main...HEAD -- src/sje/render src/sje/display src/sje/three` prints nothing, or the file is flagged so the main session runs `npm run perf` once. A flag with a clear reason does not lower the score. A silent change does. `tests/balance.test.ts` and `tests/economy.test.ts` are green.
10. Pictures and docs: the runner writes pictures of a battle (intro, command menu, a hit, victory) and the field (town, world map, a dungeon floor) at 1280x720 to `media/m8-ui/` (git-ignored). A reader flags a blank or broken one. There is no pixel comparison test. The docs (`migration.md` M8c row, `docs/roadmap/roadmap.json`, the workstream file, the `m8-brief.md` Record) make no false claim. New text is in ASD-STE100 style. Minor items are named.
Severity: Critical = hard line fails, crash, data loss. Important = wrong behavior a player/Mark would see, a test that cannot fail, a false claim. Minor = wording, name, nit.
